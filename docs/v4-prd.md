> **版本**: v4.0 | **日期**: 2026-07 | **作者**: 产品经理 Alice（许清楚）

## 1. 项目信息

| 项目 | 说明 |
|------|------|
| **项目名称** | nova2_v4 |
| **编程语言/框架** | 前端: Vite + React 19 + TypeScript + Tailwind CSS v4；后端: 腾讯云 CloudBase（云函数 Node.js + 云数据库） |
| **文档语言** | 中文 |
| **原始需求复述** | 将 nova2 铝合金画框切框算料报价系统从纯前端 localStorage 架构升级为 CloudBase 云端架构，实现：①AI API Key 后端统一管理（用户不可见）；②成本资料库全局共享；③销售→工厂领料单分享/协作；④账号间数据授权。 |

### V3 现状基线

| 维度 | V3 现状 |
|------|---------|
| 架构 | 纯前端应用（Vite + React 19 + TS + Tailwind v4） |
| 数据存储 | localStorage（浏览器本地，各用户数据隔离） |

| 三角色 | admin / sales / operator（前端 mock 权限） |
| AI 供应商 | 10 家国内大模型（deepseek/qwen/ernie/zhipu/moonshot/baichuan/doubao/yi + openai/gemini） |

## 2. 产品目标

V4 要解决的核心问题——**从「单机工具」升级为「企业级协作平台」**：

| 目标 | 核心问题 | 衡量标准 |
|------|----------|----------|
| **G1: API Key 安全统一** | 每个销售/员工各自配置 Key，成本高且有泄露风险 | API Key 100% 存储在后端云函数环境变量中，前端零暴露 |
| **G2: 成本数据全局一致** | 各销售各自维护成本库，报价基准不统一 | 成本资料库由管理员统一维护，所有用户读取同一份数据 |
| **G3: 销售→工厂领料协作** | 销售算好的用料无法直接给工厂，工厂需重新计算 | 销售一键生成领料单并分享，工厂扫码/输码即可查看，零重复计算 |

## 3. 用户故事

### 管理员（Admin）

- **US-A1**: 作为管理员，我希望在后端统一配置 AI 供应商和 API Key，这样销售和工厂人员无需各自申请 Key，也不可见 Key 明文。
- **US-A2**: 作为管理员，我希望能集中管理成本资料库（增删改材料型号/颜色/单价/重量），这样所有销售报价时使用统一的成本基准。
- **US-A3**: 作为管理员，我希望能统一设置成本费率（配件/切工/税金），这样保证全公司报价口径一致。
- **US-A4**: 作为管理员，我希望能查看所有用户生成的领料单和报价记录，这样便于审计和成本利润分析。

### 销售（Sales）

- **US-S1**: 作为销售，我希望无需配置任何 API Key 即可直接使用 AI 算料功能，这样降低使用门槛。
- **US-S2**: 作为销售，我希望报价算料完成后能生成领料单并分享给工厂，这样工厂无需重复计算就能领料。
- **US-S3**: 作为销售，我希望能选择性分享领料单中的数据（型材明细/费用明细/客户信息/简洁领料单），这样保护敏感信息（如成本利润）不外泄给工厂。
- **US-S4**: 作为销售，我希望能查看自己历史生成的所有领料单和分享状态，这样便于追踪订单进度。

### 工厂（Factory / Operator）

- **US-F1**: 作为工厂算料员，我希望通过分享码或链接直接查看销售发来的领料单，这样无需自己重新算料。
- **US-F2**: 作为工厂算料员，我希望领料单清晰展示最终材料清单（型号×数量×长度），这样直接用于领料和切割排产。
- **US-F3**: 作为工厂算料员，我希望能查看所有被分享给我的领料单列表，这样便于统一管理和查找。

## 4. 需求池（P0 / P1 / P2 分级）

### P0 — 必须实现（V4 MVP 核心架构）

| 编号 | 需求 | 验收标准 |
|------|------|----------|
| P0-1 | **CloudBase 后端搭建** | 云函数（Node.js）+ 云数据库 + 静态托管部署完成；前端可调用云函数 |
| P0-2 | **CloudBase 用户认证** | 替换前端 localStorage 模拟登录；使用 CloudBase 自带认证系统（账密登录）；前端获取云函数调用鉴权 |
| P0-3 | **三角色权限体系** | admin / sales / factory 三角色；权限矩阵按需求表严格执行（见 5.1 节）；前端按角色动态渲染导航和功能 |
| P0-4 | **AI API Key 后端代理** | API Key 存于云函数环境变量；前端调云函数 → 云函数代理调 AI API；普通用户前端零可见 Key；管理员可在后台管理配置 |
| P0-5 | **成本资料库云端化** | CostRecord 数据迁移至云数据库；管理员可增删改查；销售只读；工厂不可见；全局单一数据源 |
| P0-6 | **成本费率云端化** | PriceConfig 中的成本费率（costAccessoryPrice / costCuttingFee / costTaxRate）由管理员在云端统一设置，所有用户共用 |
| P0-7 | **报价算料功能迁移** | 现有算料逻辑适配云端数据源（成本库从云端读取）；AI 解析请求走云函数代理 |

### P1 — 应该实现（V4 核心业务价值）

| 编号 | 需求 | 验收标准 |
|------|------|----------|
| P1-1 | **领料单生成** | 销售完成报价后，可一键生成领料单；领料单包含 4 项数据模块（型材切割明细 / 费用成本明细 / 客户订单信息 / 简洁领料单） |
| P1-2 | **领料单分享授权** | 生成领料单时，可分别勾选 4 项数据是否分享；未勾选项对工厂不可见 |
| P1-3 | **分享码/链接机制** | 生成领料单后产出分享码（短码）+ 分享链接；工厂人员输入码或点链接即可查看对应领料单 |
| P1-4 | **工厂端领料单查看页** | 工厂角色有独立入口查看被分享的领料单列表；点击查看详情（仅可见被授权的数据模块） |
| P1-5 | **领料单存储与查询** | 领料单数据存入云数据库；销售可查看自己生成的列表；管理员可查看所有；工厂可查看被分享的 |

### P2 — 可以后续实现（V4 增强项）

| 编号 | 需求 | 验收标准 |
|------|------|----------|
| P2-1 | **V3 localStorage 数据迁移工具** | 提供一次性迁移脚本/页面，将用户本地成本库数据导入云端 |
| P2-2 | **操作日志审计** | 记录关键操作（AI 调用 / 成本库变更 / 领料单生成与分享）；管理员可查看日志 |
| P2-3 | **数据导出** | 领料单 / 报价记录 / 成本库导出为 Excel 或 PDF |
| P2-4 | **领料单状态管理** | 领料单状态流转：待领料 → 已领料 → 已完成；工厂标记状态，销售可见 |
| P2-5 | **多供应商负载均衡** | 管理员配置多个 AI 供应商，云函数自动选择可用/最优供应商 |

### 5.2 登录页改造

**现状**: 前端 LoginForm，localStorage 模拟登录，含快速登录按钮（admin/sales/operator）。

**V4 改造**:
- 替换为 CloudBase 用户认证组件（账密登录）
- 移除「快速登录」演示按钮（真实环境不再需要）
- 移除前端注册功能（用户由管理员在后台创建）
- 保留现有视觉风格（indigo 主色调、圆角卡片）
- 登录成功后由 CloudBase 返回用户角色信息，前端据此渲染权限

### 5.3 设置页改造（SettingsPanel）

**现状**: 所有用户可见 AI 多供应商配置（10 个 Tab），含 API Key 输入、Base URL、模型选择。

**V4 改造**:
```
设置页（admin 视角）
├── AI 供应商配置 ← 仅 admin 可见
│   ├── 供应商列表（10 家）
│   ├── 每家：API Key（密文显示）/ Base URL / 模型 / 启用开关
│   ├── 测试连接按钮
│   └── 保存到云端（云函数环境变量）
├── 成本费率设置 ← 仅 admin 可见
│   ├── 配件单价 / 切工单价 / 税率（成本轨）
│   └── 配件单价 / 切工单价 / 税率（报价轨）
├── 用户管理 ← 仅 admin 可见
│   ├── 用户列表（用户名 / 角色 / 显示名 / 创建时间）
│   ├── 新增用户（分配角色）
│   └── 编辑/删除用户
└── 个人信息 ← 所有角色可见
    └── 修改显示名 / 密码

设置页（sales 视角）
└── 个人信息 ← 仅此一项可见
    └── 修改显示名 / 密码

设置页（factory 视角）
└── 个人信息 ← 仅此一项可见
    └── 修改显示名 / 密码
```

> **关键变更**: 销售和工厂角色的设置页**完全隐藏** AI 配置区块。当前 V3 中 AI 配置对所有用户可见，V4 必须改为仅 admin 可见。

### 5.4 成本资料库页面改造（CostDatabasePanel）

**现状**: 所有用户可增删改成本记录。

**V4 改造**:
- **管理员模式**: 保持现有完整功能（增删改查 + 批量导入 + 费率设置）
- **销售只读模式**:
  - 隐藏「新增」「编辑」「删除」按钮
  - 隐藏成本费率设置区域（成本利润费率 admin 专属）
  - 仅保留搜索 + 表格只读展示
  - 表格中 `materialCost`（材料底价）列对销售**隐藏**（敏感成本数据），仅显示型号/颜色/重量
- **工厂角色**: 导航中不显示成本资料库入口

## 6. 技术约束

| 约束 | 说明 |
|------|------|
| **后端平台** | 腾讯云 CloudBase Serverless（云函数 Node.js + 云数据库 NoSQL） |
| **前端** | 保持现有 Vite + React 19 + TypeScript + Tailwind CSS v4 |
| **认证** | CloudBase 用户认证系统（替换 localStorage mock 认证） |
| **部署** | 前端构建产物部署至 CloudBase 静态托管 |
| **AI 代理** | 云函数环境变量存储 API Key；前端 → 云函数 → AI API |
| **向后兼容** | V3 localStorage 中的成本库数据需可迁移至云端（P2 迁移工具） |
| **数据安全** | API Key 不可出现在前端代码/网络请求明文中；成本利润数据默认不分享给工厂 |
